# @teknixglobal/medusa-vietnam-core

Shared helpers for the Vietnamese payment providers in [medusa-vietnam](https://github.com/teknixglobal/medusa-vietnam): VND amounts, HMAC and constant-time compare, return URL allow-list, the `next_action` type, vi/en labels. Installed as a dependency of the gateway packages; you do not need to install it yourself.
